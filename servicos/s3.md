# Armazenamento S3

O container do app é recriado a cada deploy, e o que foi salvo no disco se perde: fotos de perfil, uploads, o `MEDIA_ROOT` do Django. Arquivos que precisam ficar vão para o Armazenamento S3.

## O que o Fabroku cria

Quando você cria o serviço, o Fabroku:

1. cria um bucket;
2. cria uma chave que só acessa esse bucket;
3. limita o bucket a 1 GB;
4. grava as variáveis abaixo no app.

## Variáveis

```bash
S3_URL=https://CHAVE:SEGREDO@s3.fabricadesoftware.ifc.edu.br/meu-bucket
AWS_ACCESS_KEY_ID=...
AWS_SECRET_ACCESS_KEY=...
AWS_STORAGE_BUCKET_NAME=meu-bucket
AWS_S3_ENDPOINT_URL=https://s3.fabricadesoftware.ifc.edu.br
AWS_S3_REGION_NAME=garage
AWS_S3_ADDRESSING_STYLE=path
```

## Django

```bash
pip install "django-storages[s3]"
```

```python
# settings.py
STORAGES = {
    'default': {'BACKEND': 'storages.backends.s3.S3Storage'},
    'staticfiles': {'BACKEND': 'whitenoise.storage.CompressedManifestStaticFilesStorage'},
}
AWS_QUERYSTRING_AUTH = True
```

O django-storages lê as variáveis `AWS_*` sozinho. Com isso, `ImageField` e `FileField` salvam no bucket.

## boto3

```python
import os
import boto3

s3 = boto3.client('s3')  # lê as variáveis AWS_*
s3.upload_file('foto.jpg', os.environ['AWS_STORAGE_BUCKET_NAME'], 'fotos/foto.jpg')
```

## Mostrar arquivos na página

O bucket é privado. Para exibir uma imagem, use a URL assinada (`arquivo.url` no Django). Ela expira depois de um tempo.

## Desvincular e excluir

Desvincular tira as variáveis do app e mantém os arquivos. Excluir apaga o bucket e todos os arquivos.
