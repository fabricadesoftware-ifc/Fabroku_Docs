# llms.txt

O Fabroku publica a documentação em texto puro, num formato feito para IAs ler: o [llms.txt](https://llmstxt.org).

| Arquivo | O que tem |
|---|---|
| [`/llms.txt`](https://fabroku.fabricadesoftware.ifc.edu.br/llms.txt) | Índice curto: o que é o Fabroku, os comandos básicos e onde está o resto |
| [`/llms-full.txt`](https://fabroku.fabricadesoftware.ifc.edu.br/llms-full.txt) | A referência inteira da CLI, do MCP, do Procfile e dos serviços num arquivo só |

## Como usar

Cole o link na conversa e peça para a IA ler antes de responder:

```
Leia https://fabroku.fabricadesoftware.ifc.edu.br/llms-full.txt
e me ajude a fazer o deploy do meu projeto Django no Fabroku.
```

No Cursor, adicione o link em **Settings → Docs** e chame com `@Fabroku` no chat.

Para a IA operar o Fabroku (ver logs, rodar migrations, fazer deploy), use o [MCP](/ia/mcp). O llms.txt só ensina; quem executa é o MCP.
